# MY 근무표 (갤럭시)

승무원 근무표를 폰에서 바로 보는 앱입니다. 근무표·다이아·휴게 알람·홈 위젯을 지원해요.

> 개인이 만든 비공식 앱이며 어떤 기관·회사와도 아무 관련이 없습니다. 아이디·비밀번호는 폰에만 저장되고 외부로 나가지 않아요.

아이폰은 [앱스토어](https://apps.apple.com/kr/app/id6784091185)에서 받으면 되고, 아래는 **갤럭시/안드로이드** 설치 방법입니다.

---

## 📲 설치 방법

1. 폰에서 최신 버전 다운로드 페이지를 엽니다.
   👉 https://github.com/KangSukWoo1/korail_shift_release/releases/latest

2. 아래로 조금 내려서 **Assets** 안의 **korail_shift_(버전).apk** 파일을 누르면 다운로드가 시작돼요.

3. 다운로드가 끝나면 알림을 눌러 파일을 열고 **설치**를 누릅니다.

4. 처음엔 "이 출처의 앱은 설치할 수 없어요" 같은 안내가 뜰 수 있어요. **설정 → 이 출처 허용** 을 켜주면 됩니다.

5. 설치 중 **Play 프로텍트** 경고가 뜨면 **"무시하고 설치"** 를 누르세요. 플레이스토어가 아닌 곳에서 받은 앱이라 뜨는 것이고 정상입니다.

6. 그래도 막히면 삼성 **자동 차단** 때문이에요.
   설정 → 보안 및 개인정보 보호 → **자동 차단** 을 잠깐 끄고 설치한 뒤 다시 켜면 됩니다.

---

## 🔄 업데이트

새 버전이 나오면 앱을 켤 때 알아서 알려줍니다. 알림이 뜨면 눌러서 받으시면 돼요. 따로 스토어를 확인할 필요는 없습니다.

---

## 🛠 첫 화면에서 멈추거나 업데이트 안내가 안 뜰 때

예전 버전은 앱 안에서 업데이트 안내를 볼 수 없는 경우가 있어요. **앱을 지우지 말고** 위 설치 방법대로 최신 파일을 받아 그대로 설치하면 덮어써집니다. 로그인 정보와 설정은 그대로 남아요.

- 설치된 버전 확인: 폰 설정 → 애플리케이션 → MY 근무표(예전 이름 '코레일 근무표') → 맨 아래 **버전**
- 다운로드 폴더에 예전 apk 파일이 남아 있으면 헷갈리니 지워 주세요. 파일 이름에 버전이 적혀 있습니다.

---

## ⏰ 알람

- 무음·진동 모드에서도 울립니다. 크기는 폰의 **알람 음량**을 따라가고, 너무 작게 돼 있으면 울리는 동안만 키웁니다.
- 방해금지를 **완전 무음**(알람까지 차단)으로 두면 울리지 않아요.
- 앱 알림을 꺼 두면 소리는 나지만 잠금 화면에 알람 화면이 안 뜹니다. 알림은 켜 두세요.
